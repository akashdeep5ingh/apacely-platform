## Registry contract

The trusted binding `QUALIFICATION_HMAC_KEY_REGISTRY` is a JSON array containing 1–258 descriptors for at most 129 independent source families. The parser rejects record 259 before secret access or crypto and validates the complete nonsecret descriptor set, source count and rotation constraints before capturing secret material. Its UTF-8 and character ceiling is **200,596 bytes/characters**, computed from 129 maximal canonical current/next pairs: 129 × (778 + 775) descriptor bytes plus 257 commas and two brackets. Each maximum uses a 122-byte secret-slot name, three 128-byte identifiers and three 24-byte timestamps; the optional-null revocation field is budgeted as a full timestamp. Noncanonical escaping or whitespace must fit this same byte ceiling. This is an offline parser budget, not a Workers environment-variable-size claim. Every descriptor must have exactly these own enumerable data fields:

- `slot`: `current` or `next`.
- `secret_slot`: a distinct binding name matching `^QUALIFICATION_SIGNING_KEY_[A-Z][A-Z0-9_]{0,95}$`.
- `key_id`, `principal`, `source`: bounded canonical identifiers, each matching `^[A-Za-z0-9_.:-]{1,128}$`.
- `environment`: exactly `staging`.
- `provider`: exactly `synthetic`.
- `route`: exactly `/v1/ingress/synthetic`.
- `not_before`, `not_after`: canonical UTC millisecond timestamps, with the first strictly before the second.
- `revoked_at`: explicit null or a canonical UTC millisecond timestamp.

Every distinct source has exactly one current descriptor and at most one next descriptor. Those descriptors must share the same principal; repeated source/slot pairs and more than five minutes of overlap are rejected. Independent sources can coexist with independent rotations. Nonoverlapping lifecycle windows remain permitted, matching baseline semantics.

Key IDs and secret-slot names are globally unique. Canonical secret strings must encode exactly 32 bytes of RAM-only test material, must be own enumerable data bindings, and cannot alias any other current/next material, including across sources. Unexpected `QUALIFICATION_SIGNING_KEY_` bindings are rejected. Inherited bindings, hidden/accessor authority and malformed descriptors fail closed without invoking secret accessors. Secret values are never included in error messages or evidence. The parser captures frozen records and secret-string snapshots; decoding, duplicate-material cryptographic checks, and nonextractable HMAC import occur inside retained lazy verification.

The registry is a server allowlist, not tenant membership. The selected key establishes its configured principal/source only after real cryptographic verification. The existing active, versioned D1 mapping determines tenant and source binding. Tenant/environment/protocol/tier fields supplied by a caller do not select authority. Mapping revocation and replay/acceptance guards remain enforced by existing code.
